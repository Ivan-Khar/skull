Have you ever wanted to live in terror? Now you can, with skull(💀) that would follow you till you die.

This mod is server-side but you can install it on client to edit the config file

## Configuration
- You can access configuration file with ModMenu(or alternatives) OR
- Manually edit configuration file in `<minecraft>/config/theaq/skull-common.json`

By default skull spawns when theres at least 2 players on the server
